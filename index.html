Zola 0.23 基准实测子站（Rust + Tera v2 单体二进制引擎）

本子站（page2401/zola）由主仓库 page2401.github.io/docs/ 的标准 GitHub Flavored Markdown（GFM）母版派生适配而来，用于实测 Rust 社区代表性通用静态网站生成器 Zola v0.23.6（升级内置 Tera v2 组件引擎、Giallo 高亮器与 pulldown-cmark）的毫秒级构建与跨代破坏性变更。

锁定版本与技术栈档案

模块 / 组件锁定版本角色与实测说明
zola0.23.6Rust 单体二进制全功能 SSG（内置 Giallo 高亮、Sass 编译与编译期死链校验，全站构建仅约 20ms）
